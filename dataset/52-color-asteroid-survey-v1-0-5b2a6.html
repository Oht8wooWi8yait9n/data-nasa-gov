Description

The observations were made using a double CVF (circularly variable filter). The short wavelength portion of the CVF covered the octave from 0.8 to 1.6 microns with 3 percent resolution, while the long wavelength portion covered 1.5 to 2.6 microns with 5 percent resolution. There is some overlap in the spectral coverage between 1.5 and 1.6 microns, which is evident as a discontinuity in the wavelengths after the first 32 values, which were obtained with the short wavelength portion, while the remaining 20 values were obtained with the long wavelength portion.
