ACE Electron Proton Alpha Monitor (EPAM) CA60 PHA Ion SEP Event Matrix Data, 17 min Averages

HeliophysicsScience Discovery EngineAccess: public

Description

Pulse Height Analyzer matrix data for a single Solar Energetic Particle event from the ACE:EPAM instrument. Using the PHA data, one can quickly and very accurately determine composition.
