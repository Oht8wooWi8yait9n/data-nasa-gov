Earth ScienceScience Discovery EngineAccess: public

Description

This data set contains 76 active-layer depth measurements (cm) of the Vaisjeäggi palsa bog, Finland, from 08 September 1993 to 14 October 2002. Data were collected from a single location at 69 deg 49'16.6' N, 27 deg 10'17.1' E. Data also contain snow depth (cm) when snow cover was present. Data are in tab-delimited ASCII text format, and are available via ftp.
