Description

The AMSR2 Daily Polar Gridded Brightness Temperatures product provides daily polar stereographic gridded daily brightness temperatures for both the Northern and Southern Hemispheres. As this product is intended to provide a follow-on data set for Near-Real-Time DMSP SSMIS Daily Polar Gridded Brightness Temperatures (NSIDC-0080), it uses TB fields gridded to match TBs gridded from SSMIS sensors on the same 25km polar stereo grids.
