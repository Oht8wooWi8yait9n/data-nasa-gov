Description

Apollo Surface Panoramas is a digital library of photographic panoramas that the Apollo astronauts took while exploring the Moon's surface. These images provide a spectacular boots-on-the-ground view of the lunar landscape. Lunar surface features captured in the panoramas can be studied using zoom and pan tools. An annotated version of each panorama is also available to assist users with the identification of major geographic features around each Apollo landing site.
