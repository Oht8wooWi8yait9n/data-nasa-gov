Earth ScienceDNG Legacy DataAccess: public

Description

This dataset contains Earth-based, polarimetric radar image data for Venus collected from 1988 onwards, using the Arecibo Observatory 12.6-cm (2380 MHz) transmitter and receivers at either Arecibo or the Green Bank Telescope in West Virginia.
