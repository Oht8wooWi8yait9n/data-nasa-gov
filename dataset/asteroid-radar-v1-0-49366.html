Description

This dataset is intended to include all asteroid radar detections. An entry for each detection reports radar cross-section and circular polarization, if known, as well as the year of observation and the reference in which the observations were reported. Observations which have not been published yet, or which have been reported only in an abstract, are included as an entry but with no data.
