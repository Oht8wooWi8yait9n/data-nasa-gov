Description

The Auriga-California molecular cloud is a large region of relatively modest star formation that is part of the Gould Belt. The "Auriga-California Molecular Cloud" (ACMC) Herschel program observed a 14.5 square degree area in five far-infrared bands.\n\nThe ACMC catalog provides photometry for the 60 point-like and very compact sources in each band: PACS 70 and 160 microns, SPIRE 250, 350, and 500 microns.
