Automated Event Service: Efficient and Flexible Searching for Earth Science Phenomena Project

Earth ScienceDNG Legacy DataAccess: public
View Official Record on data.nasa.gov

Description

&lt;p&gt; Develop an Automated Event Service system that:&lt;br /&gt; Methodically mines custom-defined events in the reanalysis data sets of global atmospheric models.&lt;br /&gt; Enables researchers to specify their custom, numeric event criteria using a user-friendly web interface to search the reanalysis data sets.&lt;br /&gt; Supports Event Specification Language (ESL) for more flexibility and versatility.&lt;br /&gt; Contains a social component that enables the dynamic formation of collaboration groups for researchers to cooperate on event definitions of common interest.&lt;br /&gt; Provides rapid results via high performance computing and advanced search technologies.&lt;br /&gt; &amp;nbsp;&lt;/p&gt;
