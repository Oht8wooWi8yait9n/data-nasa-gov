Description

This data set consists of all of the fits (both good and bad) that were found by Dr. Robert J. Wilson during the NASA Cassini Data Analysis Program grant (NNX12AG90G). The Cassini CAPS plasma data used in the forward model plasma parameter calculations given here came from volume CO-E/J/S/SW-CAPS-2-UNCALIBRATED-V1.0 in the Planetary Data System (PDS).
