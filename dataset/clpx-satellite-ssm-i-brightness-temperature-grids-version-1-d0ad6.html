Earth ScienceScience Discovery EngineAccess: public

Description

This data set includes Defense Meteorological Satellite Program (DMSP) F-13 passive microwave brightness temperatures gridded to the geographic (lat/long) and UTM grids of the Cold Land Processes Field Experiment (CLPX) Large Regional Study Area (LRSA).
