CONTOUR REMOTE IMAGING SPECTROGRAPH GROUND OCF IMAGE DATA

Planetary ScienceScience Discovery EngineAccess: public

Description

This dataset contains raw counts from the the imager of the CONTOUR Remote Imaging Spectrograph (CRISP) instrument during ground calibration in the Optical Calibration Facility (OCF) at JHU/APL in 2002.
