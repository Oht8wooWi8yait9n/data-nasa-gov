Description

Abstract ======== Framing Camera 1 is one of two identical units flying on Dawn spacecraft. This dataset includes the image files to be used in the calibration of the raw data throughout the mission. These files represent the behaviour of each individual pixel with respect to dark current generation and pixel-to-pixel non-uniformity as a function of the filter. As these are elaborated image products, not obtained from a specific image acquisition, they do not have any ancillary data.
