Description

Abstract : This data set contains a Ceres regional digital terrain models and associated clear filter mosaics based on the Dawn Low Altitude Mapping orbit (LAMO) Framing Camera 2 (FC2) images and derived by using the stereo photo-grametric (SPG) method. The LAMO DTMs/mosaics covers the regions around the following features: Ahuna Mons and the Occator, Ernutet, Haulani, Ikapati, Kupalo/Juling, and Yalode craters. The DTM has a lateral spacing of 32 m/pixel (256 pixel/degree) and a vertical accuracy of about 1.5 m.
