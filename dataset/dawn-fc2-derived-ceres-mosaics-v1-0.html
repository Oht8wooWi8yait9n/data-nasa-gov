Description

Abstract ======== This accumulating data set includes Ceres global mosaics and quadrangles derived from images acquired by the Framing Camera 2 (FC2) on the NASA Dawn spacecraft. Global mosaics are provided in cylindrical and polar stereographic projections. The quadrangle mosaics use Mercator (equatorial), Lambert conformal (mid-latitude) and stereographic projections. Clear and color mosaics are provided for high altitude mapping orbit (HAMO) and clear filter mosaics only in the low altitude mapping orbit (LAMO) science phases. This data set spans three PDS archive volumes which were created at different times during the mission. Volume DWNCHCFC2_2 contains HAMO clear filter mosaics, DWNCHFFC2_2 contains HAMO color filter mosaics, and DWNCLCFC2_2 contains LAMO clear mosaics.
