Description

The GRaND Reduced Data Records (RDR) contain a timeseries of calibrated spectra, counting data, and ephemeris, pointing,and geometry (EPG) data. The EPG data are contained in a single file,with an entry for every science data record acquired by GRaND within thedataset start-stop times. Each record has a unique identifier,spacecraft clock ticks, which is used as a serial number to identify datafrom the same record in other files containing spectra and counting data.The RDR data set includes a time series of corrected gamma ray spectraacquired by GRaND's bismuth-germanate (BGO) scintillator.
