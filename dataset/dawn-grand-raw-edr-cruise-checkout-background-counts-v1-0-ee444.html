Description

The GRaND EDR are a time-ordered collection of gamma rayand neutron counting data and histograms acquired by GRaND during all phasesof the Dawn mission. The dataset includes state-of-health data, suchas temperature and voltage readings, needed for the analysis of the countingdata. The EDR is an intermediate data product derived from the raw datarecords using reversible operations. All higher order data products arederived from the EDR. An automated pipeline is used to process the EDR fromthe raw data records.
