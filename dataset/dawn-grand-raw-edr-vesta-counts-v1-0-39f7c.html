Description

The GRaND EDR are a time-ordered collection of gamma rayand neutron counting data and histograms acquired by GRaND during allphases of the Dawn mission. The dataset includes state-of-health data,such as temperature and voltage readings, needed for the analysis of thecounting data. The EDR is an intermediate data product derived from theraw data records using reversible operations. All higher order dataproducts are derived from the EDR. An automated pipeline is used toprocess the EDR from the raw data records.
