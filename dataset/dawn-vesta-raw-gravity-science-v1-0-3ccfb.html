Description

This data set contains archival raw, partially processed, andancillary/supporting gravity science data acquired during the Dawnmission while the spacecraft was in orbit around the asteroid Vesta.The radio observations were carried out using the Dawn spacecraft andEarth-based receiving stations of the NASA Deep Space Network (DSN).The data set was designed primarily to support generation ofhigh-resolution gravity field models for Vesta. Of most interest arelikely to be the Orbit Data Files in the ODF directory, which providedthe raw input to gravity investigations, as well as the ionospheric andtropospheric media calibration files in the ION and TRO directories,respectively.
