Description

This data set contains the spectral radiance (W/(m**2*sr*micron)) data from the Dawn VIR instrument infrared channel for all Vesta encounter mission phases. The data in this version of the data set have been produced using an updated calibration. The data cover the time period between 2011-05-03 and 2012-07-18.
