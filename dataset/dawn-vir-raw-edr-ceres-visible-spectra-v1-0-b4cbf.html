Description

This volume contains the digitalnumbers (DN) contained in the telemetry (TM) packages of the VIR-VISinstrument on board of the spacecraft DAWN. The data are from theCeres Encounter and Extended mission phases, which occurred 2014-12-26to 2017-04-29.
