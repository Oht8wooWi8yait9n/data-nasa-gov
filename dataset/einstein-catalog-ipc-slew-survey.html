Description

This database table contains the list of sources detected in the IPC Slew Survey. It was created in March 1992 and contains 819 entries. The original IPC Slew Survey source list was released on CD-ROM and contained 1067 sources. The list was updated in 1991 to remedy a software bug which omitted a thin slice of RA near 24h; the bug fix yielded 8 additional sources, to bring the total to 1075. The list, however, was found to contain a large fraction (10 to 15 percent) of unreliable sources, especially those sources with &lt;= 5 photons. The unreliable sources were rejected in producing the latest version of the source list, so that it now has an estimated false source rate of only 2 percent, and contains 256 fewer sources than the previous version. The previous version of the source list, with 1075 sources, has been retained in a database called OLDIPCSLEW. The HEASARC implemented this database table in March 1992.
