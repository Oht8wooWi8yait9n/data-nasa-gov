Description

This data set set contains version 1.0 of raw 750-nm filter images of Earth acquired by the Deep Impact Medium Resolution Visible CCD during the EPOCh phase of the EPOXI mission. The MRI instrument was only used during first Earth observing period on 18-19 March 2008. The observing period lasted approximately 24 hours, and one MRI image was taken simultaneously with the first north/south scan of the HRI IR spectrometer at half-hour intervals. These MRI data serve as context images for the IR spectral scans. Additional Earth observations are planned for the mission, and, if acquired, MRI images will be added to a future version of this data set.
