Description

The datasets contain the retrieved aerosol and ocean color properties from AirHARP measurements using the FastMAPOL algorithm. Three scenes (5Mb each) are included in the zip file: FastMAPOL_ACEPOL_AIRHARP_L2_ER2_20171023201049_V1.1.nc FastMAPOL_ACEPOL_AIRHARP_L2_ER2_20171023213049_V1.1.nc FastMAPOL_ACEPOL_AIRHARP_L2_ER2_20171023204956_V1.1.nc Details of the retrieval algorithm are discussed in the following work: Gao, M., Franz, B. A., Knobelspiesse, K., Zhai, P.-W., Martins, V., Burton, S., Cairns, B., Ferrare, R., Gales, J., Hasekamp, O., Hu, Y., Ibrahim, A., McBride, B., Puthukkudy, A., Werdell, P. J., and Xu, X.: Efficient multi-angle polarimetric inversion of aerosols and ocean color powered by a deep neural network forward model, Atmos. Meas. Tech., 14, 4083–4110, https://doi.org/10.5194/amt-14-4083-2021, 2021. Algorithm highlights: - The algorithm conducts simultaneous aerosol and ocean color retrievals using multi-angle polarimetric measurements. - Remote sensing reflectance is derived through atmospheric correction using the retrieved aerosol properties. - Neural networks are used to speed up the forward model and various processing steps.
