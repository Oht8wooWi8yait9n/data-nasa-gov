Description

This data set is a simulated data set based on the flight simulator "FLTz" used by the Intelligent Flight Control (IFC) group at NASA ARC. Flights were preprogrammed to fly through randomly generated circular flight paths starting from San Francisco International Airport (SFO) and ending at approximately the same location. No known anomalous flights were simulated.
