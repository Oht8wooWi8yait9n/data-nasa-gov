Earth ScienceDNG Legacy DataAccess: public

Description

This dataset includes open- and closed-loop data from the Giotto Radio Experiment (GRE) during the time range +/- 3 minutes around close approach. In both cases the data were received by station 63 in Madrid. These data were never formally reviewed by PDS.
