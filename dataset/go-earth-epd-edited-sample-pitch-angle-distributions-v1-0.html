Description

This data set contains sixteen sector rate data for the energetic particle detector obtained from the LEMMS and CMS telescopes during the time of significant activity during the Earth encounter on day 343, 1992. A data file record contains a single sector's data for a particular LEMMS or CMS channel. Also included are pitch and phase angles of the particles counted by the detectors.
