Description

The GPM Ground Validation National Mosaic and Multi-Sensor QPE (NMQ) System IFloodS dataset contains quality control products, real time rain rate estimates, hourly precipitation rate estimates, and three-dimensional reflectivity products. These data products are also referred to as Multi-Radar Multi-Sensor Precipitation Reanalysis for Satellite Validation (MRMS) product and were created using the NOAA NMQ System which ingests Weather Surveillance Radar 88 Doppler (WSR-88D) radar data, Rapid Update Cycle (RUC) model analysis fields, and Hydrometeorological Automated Data Systems (HADS) gauge data. The files provided in this dataset are from the NMQ system output obtained during the GPM Iowa Flood Studies (IFloodS) field campaign that occurred throughout Iowa. These data are available in ASCII, netCDF-4, and binary formats for the dates between April 1, 2013 through June 30, 2013.
