Description

The GSFC Ozone Profile Climatology: MLS/GMI Seasonal and REOF Interannual product (O3CLIM_MLSGMI_REOF) is comprised of two components: (1) a 12-month seasonal climatology based on Aura MLS stratospheric and M2GMI tropospheric ozone, and (2) a time-dependent inter-annual climatology based on the rotated emperical orthogonal function (REOF) method. These two components are added together to derive a 5 degree zonal mean profile ozone climatology. The data are stored in a single version 5 Hierarchical Data Format (HDF5) file. Data are monthly and zonally averaged at 5 degree resolution, from 0 to 80 km at 1km increments. The single data file size is 339 MB.
