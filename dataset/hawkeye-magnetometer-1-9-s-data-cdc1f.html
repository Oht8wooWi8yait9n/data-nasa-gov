Hawkeye Magnetometer 1.9-s Data

HeliophysicsScience Discovery EngineAccess: public
View Official Record on data.nasa.gov

Description

This level 0 data set contains investigator-provided magnetic field data at 1.9-second resolution from the Hawkeye magnetometer instrument. The data set contains despun data including the following parameters: scalar magnetic field strength; vector magnetic field in Cartesian GSM and SM coordinates; spacecraft radial distance from the center of Earth; spacecraft position in Cartesian GSM and SM coordinates; despin method indicator (0: not despun; 1: optical aspect; 2: sun pulse; 3: array voltage; 4: mag field model; 4/5: solar array method); and an estimate of the angular uncertainty in magnetic field direction (set to zero for despin = 1 or 2). For a reference paper on despinning technique, see Boardsen, S. and R.L. Kessel, Spin Index Determination of the Hawkeye Spacecraft, J. Spacecraft and Rockets, 39, 780-787, 2002.
