Description

This data set includes the complete set of Hayabusa SPICE data files (``kernel files'') for the surveying and collection phases of the mission. The SPICE data files, which can be accessed using SPICE software, contain geometric and other ancillary information needed to recover the full value of the science instrument data. In particular SPICE kernels provide spacecraft and planetary ephemerides, instrument mounting alignments, spacecraft orientation, spacecraft sequences of events, and data needed for relevant time conversions.
