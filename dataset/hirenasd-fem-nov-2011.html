Description

Model with Tetrahedral elements includes wing, balance, exciter and modelcart Some files were too large and had to be split into parts. To combine the parts, use cat filename_part1 filename_part2 > filename. <img src="https://c3.nasa.gov/dashlink/static/media/dataset/tableoffreq.png" width=400> A <a href="https://c3.nasa.gov/dashlink/static/media/dataset/TET_nov2011_modeshapes.pdf"">PDF</a> file with figures of the mode shapes is available.
