Description

These grids were constructed using Centaur software at DLR in Germany. The grids designed for node based (labeled 'cv') and cell-centered solvers (labeled 'cc') are supplied. Grids with mixed elements only are supplied. Each mixed elements tar-file contains grid in TAU software native format '.nc','.bmap'. The grid was converted into '.cgns' format. In some instances, the grids in TAU native formats were converted into aflr3 format at NASA Langley '.ugrid','.mapbc' which in turn were converted to the 'ugrid.cgns' formats. Some files were too large and had to be split into parts. To combine the parts, use cat filename_part1 filename_part2 > filename. Grids are in units of 'mm'. Please report any issues with these grids to Markus.Ritter@dlr.de and Pawel.Chwalowski@nasa.gov
