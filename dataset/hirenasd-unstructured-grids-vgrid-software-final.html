Description

These grids were constructed using VGRID software from NASA Langley. The grids designed for node based (labeled 'nc') and cell-centered (labeled 'cc') solvers are supplied. Grids with mixed elements (labeled 'mixed') and tetrahedral elements (labeled 'tets') are supplied. Each mixed elements tar-file contains grid in aflr3 .ugrid format and the corresponding .cgns file. Each tetrahedral elements tar-file contains grid in native VGRID format (.cogsg, .bc, .mapbc) and the corresponding .cgns file. Some files were too large and had to be split into parts. To combine the parts, use cat filename_part1 filename_part2 > filename. Grids are in units of 'mm'. Information about grids, that is number of nodes, elements, etc., is provided in AePW_HIRENASD_Grid_Statistics_VGRID_Final.docx Please report any issues with these grids to Pawel.Chwalowski@nasa.gov The mode shapes from NASTRAN interpolated on the surface mesh are available for some of the grids. These files are in Tecplot format and units of 'meter.' Please note that the coarse and medium grids for the mixed elements node based solvers are at the bottom of the list.
