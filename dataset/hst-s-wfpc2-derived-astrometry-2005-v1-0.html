Description

This dataset contains astrometric data for fourteen Saturn satellites: Calypso, Dione, Enceladus, Epimetheus, Helene, Hyperion, Janus, Mimas, Pandora, Prometheus, Rhea, Telesto, Tethys, and Titan. The data were obtained using the HST/WFPC2 over the period 1996-2005.
