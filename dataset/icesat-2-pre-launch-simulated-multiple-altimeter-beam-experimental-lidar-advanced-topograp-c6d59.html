Description

Multiple Altimeter Beam Experimental Lidar (MABEL) Advanced Topographic Laser Altimeter System (MATLAS) simulates the expected performance of the ICESat-2 ATLAS instrument. The data are produced from MABEL data by adjusting the detected number of signal and noise photons to that predicted using ATLAS instrument model design cases. Each data file consists of approximately 1 minute of HDF5-derived MABEL data.
