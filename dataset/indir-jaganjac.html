Description

FLTz flight simulator RecorderRun9 data are analyzed in order to compute systems health score using Granger causal connectovity analysis. First G-causality is computed, and then causal density (cd) is computed in interval [0,1]. Numerical value of causal density for this data file is 0.4711, which corresponds to systems health score.
