Description

The IRAS Point Source Catalog Redshift (PSCz) Survey consists of redshifts, infrared and optical photometry, and assorted other information for 18351 IRAS sources, mostly selected from the Point Source Catalog. The survey was designed to select almost all galaxies with flux brighter than 0.595 Jy at 60 microns (&micro;m), over the 84% of the sky with extinction small enough that reliable and complete optical identification and spectroscopy was possible. Some of the sources are not galaxies and some are multiple entries for the same galaxy as described in the reference paper. There are in total 15,411 galaxies or possible galaxies, for which redshifts are available for 14,677. The galaxies without redshift are mostly distant or at low latitude, as described in the paper. Many of these galaxies have now been observed as part of the BTP project (Saunders et al 1999, astro-ph/9909174 &quot;The Behind the Plane Survey&quot;), and their redshifts were to be included in future revisions of this catalog. The full catalog for the PSCz Catalog contains more than 120 parameters and is available at the CDS in the directory &lt;a href="http://cdsarc.u-strasbg.fr/ftp/cats/VII/221/"&gt;http://cdsarc.u-strasbg.fr/ftp/cats/VII/221/&lt;/a&gt; as the files pscz.dat (18,351 sources in the main catalog) and psczcg.dat (60 additional sources close to the coverage gap). There is also a &#39;short&#39; version of the catalog, psczvs.dat and psczcgvs.dat, containing 19 parameters, sufficient information for most studies. They correspond to the version 2.2. Many fields are taken directly from the IRAS Point Source Catalogue (CDS Cat. II/125). See the IRAS Explanatory Supplement (Beichman et al., 1988, NASAR, 1190, 1) for more information. If there are problems that cannot be resolved by careful reading of these notes or the accompanying paper, please contact Will Saunders &lt;will@roe.ac.uk&gt; or Will Sutherland &lt;W.Sutherland1@physics.ox.ac.uk&gt;. This table was created by the HEASARC in February 2014 based on &lt;a href="https://cdsarc.cds.unistra.fr/ftp/cats/VII/221"&gt;CDS Catalog VII/221&lt;/a&gt; files psczvs.dat (the &#39;Main&#39; sample) and psczcgvs.dat (the &#39;Near-gap&#39; sample), comprising the &#39;Short&#39; version of the PSCz Catalog.
