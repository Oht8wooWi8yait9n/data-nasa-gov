ISEE-3 High Resolution Magnetic Field Data

HeliophysicsScience Discovery EngineAccess: public
View Official Record on data.nasa.gov

Description

These data are the highest-time-resolution data available from the ISEE-3 MAG instrument. The data are separated into four files per day, each with the date (YYDDD) and starting hour (00, 06, 12, or 18) embedded in the data file name. The ASCII files were compressed using gzip, and must be de-compressed before using. Some or all files from any particular day may be absent due to absence of data. Files are located in yearly sub-directories.
