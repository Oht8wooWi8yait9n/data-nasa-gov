Description

This data set contains archival results from gravity investigations conducted during the Juno mission while the spacecraft was in orbit around Jupiter. X- and Ka-band Radio measusrements were made using the Juno spacecraft and Earth-based stations of the NASA Deep Space Network (DSN). Version 1.0 includes a spherical harmonic model of Jupiter's gravity field produced by Sapienza University of Rome; these results were derived from raw radio tracking data.
