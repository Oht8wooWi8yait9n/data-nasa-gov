JUNO MOON JIRAM EXPERIMENT DATA RECORD V3.0

Earth ScienceDNG Legacy DataAccess: public
View Official Record on data.nasa.gov

Description

This dataset contains the scientific telemetry produced by the JIRAM instrument after editing for duplicated and corrupted packets, together with geometric information computed on ground to locate observations in space and time.
