Description

This data set contains global uncontrolled mosaics of the Moon in simple cylindrical projection. The images are derived from the LRO Mini-RF Map-projected Calibrated Data Records (PDS data set ID LRO-L-MRFLRO-5-CDR-MAP- V1.0).
