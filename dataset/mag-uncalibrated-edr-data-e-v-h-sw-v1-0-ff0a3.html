Description

Abstract ======== This data set consists of the MESSENGER MAG uncalibrated observations, also known as EDRs. The MAG experiment is a miniature three-axis ring-core fluxgate magnetometer with low-noise electronics. There are eight MAG EDR data products, including standard data, burst-mode data, and status and housekeeping data.
