Description

The datasets contain the retrieved aerosol and ocean color properties from AirHARP measurements using the FastMAPOL algorithm and adaptive data screening (MAPDS). One open ocean scene is included with cirrus cloud adaptive screened: ACEPOL_AIRHARP.20171023201049.L2.FastMAPOLV1.3.nc Details of the retrieval and data screening algorithm are available in the publication titled "Adaptive Data Screening for Multi-Angle Polarimetric Aerosol and Ocean Color Remote Sensing Accelerated by Deep Learning" (https://doi.org/10.3389/frsen.2021.757832)
