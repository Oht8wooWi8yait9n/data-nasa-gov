Description

This data set contains calibrated Mars Express ASPERA-3 Electron Spectrometer (ELS) data for the second mission extension (October 1, 2007 - May 31, 2009). These data are provided in units of Differential Number Flux (DNF): cnts/(cm**2-sr-sec-eV)
