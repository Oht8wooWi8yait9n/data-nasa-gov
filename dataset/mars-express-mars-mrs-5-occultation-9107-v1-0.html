MARS EXPRESS MARS MRS 5 OCCULTATION 9107 V1.0

Planetary ScienceScience Discovery EngineAccess: public

Description

This data set contains ionospheric electron density profiles as well as neutral atmospheric temperature, pressure and number density profiles derived from the MEX Radio Science experiment MaRS. The data set covers measurements from the occultation season 07.
