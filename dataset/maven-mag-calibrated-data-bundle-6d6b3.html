Description

This bundle contains MAG supplied ASCII files containing a time series of magnetic-field vectors in geophysical units (nanotesla, nT) that have been corrected for instrumental and spacecraft effects (calibrated). In addition, these data have been transformed into physically meaningful coordinate systems. MAG data products are generated for all mission phases.
