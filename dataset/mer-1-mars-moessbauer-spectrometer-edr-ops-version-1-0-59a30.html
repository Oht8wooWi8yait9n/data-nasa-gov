Description

This archive contains Mars Exploration Rover Operations (Ops)Moessbauer Experiment Data Record (EDR) products and ancillary files.Each EDR product has a detached PDS label that describes the filestructure and instrument parameters used for that image.The Moessbauer Operations EDR products archived on this volumeare the original products used during mission operations by the MarsExploration Rover project. Supporting documentation and label filesconform to the Planetary Data System (PDS) Standards, Version 3.6, JetPropulsion Laboratory (JPL) document number D-7669.
