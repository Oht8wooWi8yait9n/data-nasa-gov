Description

Abstract ======== This data set consists of the MESSENGER GRS uncalibrated observations, also known as EDRs. The GRS experiment is a gamma ray spectrometer designed to observe spectrum of gamma rays emitted from Mercury's surface in the energy range from 0.1 to 10 MeV. There are ten GRS EDR data products: the raw spectra data, the spectra data from the shield (2 versions), shield count rate data, the anti-coincident spectra data, the microphonics data, the software rate counter data, the status parameters, the state of the instrument, and a GRS instrument command list.
