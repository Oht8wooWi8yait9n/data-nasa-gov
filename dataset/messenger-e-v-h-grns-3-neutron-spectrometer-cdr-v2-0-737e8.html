Description

Abstract : This data set consists of the MESSENGER Neutron Spectrometer (NS) calibrated data records (CDRs). The NS experiment is a neutron spectrometer designed to observe spectra of neutrons emitted from Mercury's surface in the energy range from 0.01 eV to 7 MeV. There are five NS CDR data products: raw neutron spectra, NS counter data, galactic cosmic ray (GCR) spectra, engineering data, and gamma-ray burst data. This is version 2 of this data set; version 1 has been superceded.
