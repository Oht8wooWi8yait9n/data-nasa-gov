Description

This data set contains the Magellan ALT-EDR (Altimeter Experiment Data Record) archive products. It also contains documentation files which describe the ALT-EDRs. Each ALT-EDR data directory contains the raw altimeter data returned from one orbit and the ancillary files necessary to understand the data. The ALT-EDR products archived on this volume are the exact products released by the Magellan Project.
