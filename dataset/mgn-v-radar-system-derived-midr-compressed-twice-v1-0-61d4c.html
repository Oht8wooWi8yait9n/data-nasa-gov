Description

This data set contains the Magellan Compressed Twice Mosaicked Image Data Records (C2-MIDRs) which consists of mosaics generated by computing 3x3 pixel arithmetic moving averages from the C1-MIDRs. Each C2-MIDR is in a sinusoidal equal area projection and has an origin at 0 degrees latitude, with the central meridian defined as the longitude bisecting the mosaic. Each C2-MIDR has 7168 lines (aligned with latitudes) and 8192 samples, arranged as 56 1024x1024 files on CD-ROM. C2-MIDRs, with their 675 m pixel widths, are designed to cover the planet at reasonably high resolution and high signal to noise ratio.
