Description

This data set consists of calibrated, time-ordered, angle-resolvedelectron flux data from the Electron Reflectometer (ER) instrument onthe Mars Global Surveyor (MGS) spacecraft. The primary data consist oftime-series tables with descriptive headers. The data set also includesancillary data (including geometry), documentation, and browse plots.
