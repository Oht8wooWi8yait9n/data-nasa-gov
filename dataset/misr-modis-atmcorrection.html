Description

This data repository (6.36gb total) supports the publication: Knobelspiesse, K., Ibrahim, A., Franz, B., Bailey, S., Levy, R., Ahmad, Z., Gales, J., Gao, M., Garay, M., Anderson, S., and Kalashnikova, O.: Analysis of simultaneous aerosol and ocean glint retrieval using multi-angle observations, Atmos. Meas. Tech. Discuss. [preprint], https://doi.org/10.5194/amt-2020-423, in review, 2020. For more details contact Kirk Knobelspiesse, kirk.knobelspiesse@nasa.gov Last updated February 1, 2021 Contained in this directory are, besides this description file, seven zipped data directories (compressed with bsdtar 3.3.2 - libarchive 3.3.2 zlib/1.2.11 liblzma/5.0.5 bz2lib/1.0.6) with the suffix renamed to .zip to abide by NASA Open Data Portal upload requirements. Those files are: Knobelspiesse_AMT-2020-423_PLOTS_orb0.zip Knobelspiesse_AMT-2020-423_PLOTS_orb1.zip Knobelspiesse_AMT-2020-423_PLOTS_orb2.zip Knobelspiesse_AMT-2020-423_PLOTS_orb3.zip Knobelspiesse_AMT-2020-423_PLOTS_orb4.zip Knobelspiesse_AMT-2020-423_PLOTS_orb5.zip Knobelspiesse_AMT-2020-423_PLOTS_orb6.zip Each are slightly less than 1gb and contain 1008 figures. The “orb[A]” component describes observation geometry, as described in the README.
