Description

This dataset shows an example result from the MISR Maximum Likelihood (MLI) algorithm, which uses the MISR 866nm channel multi-angle observations to derive 4 parameters: - Aerosol Optical Depth (866nm) - Aerosol fine side mode fraction - Aerosol "relative humidity" (water content) - Ocean surface wind speed An information content assessment of the parameters of this retrieval can be found here: https://amt.copernicus.org/preprints/amt-2020-423/ The ultimate goal is to produce a research evaluation dataset with the MISR MLI algorithm. Results, and they become ready, will be posted here. MISR MLI is intended to act as an atmospheric correction that can be applied to coincident MODIS-Terra observations.
