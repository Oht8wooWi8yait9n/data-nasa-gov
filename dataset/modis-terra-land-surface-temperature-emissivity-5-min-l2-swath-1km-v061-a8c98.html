Description

The MOD11_L2 Version 6.1 swath product provides per-pixel Land Surface Temperature and Emissivity (LST&E) with a pixel size of 1,000 meters (m). The product is produced daily in 5-minute temporal increments of satellite acquisition using the generalized split-window algorithm. MOD11_L2 is a Level 2 product which provides the input for the Level 3 products. Provided in each MOD11_L2 file are LST, quality control assessment, error estimates, bands 31 and 32 emissivities, zenith angle of the pixel view, observation time, and the geographic coordinates for every five scan lines and samples. Known Issues * For complete information about known issues please refer to the [MODIS/VIIRS Land Quality Assessment website](https://landweb.modaps.eosdis.nasa.gov/knownissue?sensor=MODIS&sat=Terra&as=61).
