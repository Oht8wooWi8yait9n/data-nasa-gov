MSX SMALL BODIES IMAGES V1.0

Earth ScienceDNG Legacy DataAccess: public

Description

Eight comets, two transition objects, and two near-Earth asteroids were imaged in six infrared bands with the Spirit III instrument on the Midcourse Space Experiment (MSX). This data set contains the calibrated images.
