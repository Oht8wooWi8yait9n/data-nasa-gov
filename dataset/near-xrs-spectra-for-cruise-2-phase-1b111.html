NEAR XRS SPECTRA FOR CRUISE 2 PHASE

Planetary ScienceScience Discovery EngineAccess: public
View Official Record on data.nasa.gov

Description

This data set contains X-Ray Spectrometer (XRS) observations made during the second cruise phase of the NEAR mission. The individual observations are combined into a single file per day for each sensor.
