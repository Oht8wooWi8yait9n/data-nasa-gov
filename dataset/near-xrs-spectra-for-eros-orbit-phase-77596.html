NEAR XRS SPECTRA FOR EROS ORBIT PHASE

Earth ScienceDNG Legacy DataAccess: public
View Official Record on data.nasa.gov

Description

This data set contains Level 1b X-Ray Spectrometer (XRS) observations made during the Eros orbit phase of the NEAR mission. The individual observations are combined into a single file per day for each sensor.
