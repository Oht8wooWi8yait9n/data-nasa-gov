Description

This data set contains Calibrated data taken by the New Horizons Alice Ultraviolet Imaging Spectrograph instrument during the KEM1 ENCOUNTER mission phase. This is VERSION 3.0 of this data set. This data set contains data acquired by the spacecraft between 08/14/2018 and 07/31/2019. It only includes data downlinked before 08/01/2019. Future datasets may include more data acquired by the spacecraft after 08/13/2018 but downlinked after 07/31/2019. This dataset contains data from Arrokoth's encounter.
