Description

This data set contains Calibrated data taken by the New Horizons Pluto Energetic Particle Spectrometer Science Investigation instrument during the CRUISE TO FIRST KBO ENCOUNTER mission phase. This is VERSION 2.0 of this data set. This data set contains data acquired by the spacecraft between 10/22/2016 and 08/13/2018. This is the complete dataset.
