Description

This data set contains Raw data taken by the New Horizons Radio Science Experiment instrument during the CRUISE TO FIRST KBO ENCOUNTER mission phase. This is VERSION 2.0 of this data set. This data set contains data acquired by the spacecraft between 09/21/2017 and 08/13/2018. This is the complete dataset. The REX datasets over the mission include calibrations using known radio sources, Jupiter, and cold sky measurements; operational readiness tests (ORTs); internal test pattern calibration; and prime science radiometry and occultation observations during the Pluto Encounter.
