Description

This data set contains Raw data taken by the New Horizons Solar Wind Around Pluto instrument during the pluto cruise mission phase. This is VERSION 2.0 of this data set. This is Version 2.0 of this data set and supersedes Version 1.0. It contains over 2200 additional observations from late 2010 through late 2014 not included in Version 1.0; it also renamed some of the observations from Version 1.0.
