Description

This data set contains Raw data taken by the New Horizons Solar Wind Around Pluto instrument during the Pluto encounter mission phase. This is VERSION 3.0 of this data set. This data set contains SWAP observations taken during the the Approach (Jan-Jul, 2015), Encounter, Departure, and Transition mission sub-phases, including flyby observations taken on 14 July, 2015, and departure and calibration data through late October, 2016. This data set completes the Pluto mission phase deliveries for SWAP. This is version 3.0 of this dataset. Changes since version 2.0 include the addition of data downlinked between the end of January, 2016 and the end of October, 2016, completing the delivery of all data covering the Pluto Encounter and subsequent Calibration Campaign. Also, updates were made to the calibration files, documentation, and catalog files. Finally, downlink data several days beyond the end of the nominal end of mission phase were included in this data set in an attempt to fill out the products at the nominal end of mission phase; refer to the CONFIDENCE_LEVEL_NOTE in this data set catalog for more details.
