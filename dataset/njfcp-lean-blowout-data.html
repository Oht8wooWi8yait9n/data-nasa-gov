AerospaceDNG Legacy DataAccess: public

Description

Lean blowout data using fuels from the National Jet Fuels Combustion Program (NJFCP). Testing was done in the CE-13C flametube with the NASA 7-point swirl-venturi (SV-) lean direct injector (LDI) hardware.
