Description

The Level-2 Aura Ozone Monitoring Instrument (OMI) Cloud Pressure and Fraction (O2-O2 Absorption) Product (OMCLDO2) collection version 4 is now available from NASA Goddard Earth Sciences Data and Information Services Center (GES DISC) for public access.The data was re-processed in December 2022 using collection 4 Level 1b data and the OMAERO processor version 4.0.0. Since then, this version is also being produced in the forward stream. This version of the product was publicly released in March 2026. There are two Level-2 Aura OMI cloud products: OMCLDO2 and OMCLDRR. The OMCLDO2 product uses the O2-O2 absorption band at 477 nm method using the DOAS technique, whereas the OMCLDRR product uses the Rotational Raman Scattering method. This product contains cloud pressure, cloud fraction, slant column O2-O2, ozone, ring coefficients, uncertainties in derived parameters, terrain and geolocation information, solar and satellite viewing angles, and quality flags. The lead scientist for this product is Dr. Pepijn Veefkind. The OMCLDO2 files are stored in NetCDF 4 format. Each file contains data from the day lit portion of an orbit (~53 minutes). There are approximately 14 orbits per day. The maximum file size for the OMCLDO2 data product is about 12 Mbytes.
