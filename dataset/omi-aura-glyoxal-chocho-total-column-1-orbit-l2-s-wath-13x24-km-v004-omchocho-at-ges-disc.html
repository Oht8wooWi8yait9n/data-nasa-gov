Description

The Aura Ozone Monitoring Instrument (OMI) Glyoxal Product OMCHOCHO contains total vertical column CHOCHO, standard errors (rms and sigma), quality flags, geolocation and other ancillary information. The algorithm leads for this product are the US OMI scientists Gonzalo Gonzalez Abad and Hyeong-Ahn Kwon from the Harvard-Smithsonian Center, Cambridge, MA. The OMCHOCHO files are stored in the netCDF-4 format. Each file contains data from the day lit portion of an orbit (~53 minutes). There are approximately 14 orbits per day. The average file size for the OMCHOCHO data product is about 35 MB.
