HeliophysicsScience Discovery EngineAccess: public

Description

The OV19 MES.nnn files contain data from the OV1-19 Magnetic Electron Spectrometers (53 to 444 kev in 8 channels and 537 keV to 5.1 MeV in 16 channels).
