Description

The OV33.MES files contain data from the OV3-3 Magnetic Electron Spectrometers. The data were originally supplied to the National Space Science Data Center in 1971 on a set of seventeen 7-track tapes and were formatted for use on a 60-bit CDC machine. In 1993, those tapes were copied at NSSDC and supplied to Al Vampola, the original Principal Investigator, for reprocessing.
