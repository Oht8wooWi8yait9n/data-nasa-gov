Earth ScienceScience Discovery EngineAccess: public

Description

This data set includes site descriptions of paleoperiglacial features and related paleoclimatic data for Europe, including radiocarbon dating. Data have been extracted from literature published between 1952-1995 and from unpublished reports. Data are presented on the CAPS Version 1.0 CD-ROM, June 1998.
