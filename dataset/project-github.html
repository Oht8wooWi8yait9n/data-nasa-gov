Description

Release of CertWare was announced 23 Mar 2012 on: [code.nasa.gov](http://code.nasa.gov) The announcement points to the Certware project on NASA’s GitHub repository at: [nasa.github.com/CertWare](http://nasa.github.com/CertWare/) The project site contains install instructions as an Eclipse feature, various tutorials and resources, and a link to the GitHub source repository. CertWare is released under the NASA Open Source Agreement (NOSA).
