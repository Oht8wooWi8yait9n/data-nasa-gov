Description

PUNCH Level 3 polarized F-corona model derived from Wide Field Imager 3 (WFI-3) observations and represented in the PUNCH mosaic frame as an MZP (Minus, Zero, and Plus) polarization triplet, with a corresponding uncertainty array. The FITS file also includes a table containing file-processing provenance. This dataset is a member of the collection “PUNCH NFI-WFI Level 3 Science Dataset.” Per instructions from the PUNCH team, reference to the entire Collection, including the DOI below, should be used when this and other member datasets in the Collection are cited: Southwest Research Institute (2025). PUNCH NFI-WFI Level-3 Science images [Collection]. Solar Data Analysis Center. https://doi.org/10.48322/nnv7-bn21. Access date (assigned on date of landing page access).
