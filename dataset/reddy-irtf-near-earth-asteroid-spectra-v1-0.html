Description

This data set contains low-resolution near-infrared (~0.7-2.5 microns) spectra of 40 near-Earth asteroids observed with the SpeX instrument on the NASA Infrared Telescope Facility (IRTF) on Mauna Kea, Hawai'i. This data set archives reduced, calibrated spectra that were obtained as part of Vishnu Reddy's Ph.D. disseration at the University of North Dakota. They have been used for detailed mineralogical/compositional analysis and thermal modeling to constrain the albedo of these objects.
