HeliophysicsScience Discovery EngineAccess: public

Description

The imagecube FITS files containing the images in the RHESSI Flare Image Archive (which is in the flare_images_v2 directory up one level from here). These FITS files can be used as input to the RHESSI image object software, or read into an array of map structures using the routine hsi_fits2map, or read directly by a standard FITS reader.
