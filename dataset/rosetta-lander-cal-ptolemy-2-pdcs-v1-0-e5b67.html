Description

This archive contains edited data from the PTOLEMY instrument onboard ROSETTA Lander, acquired during the PDCS mission phase. It also contains documentation which describes the PTOLEMY experiment. The data archived in this data set conform to the Planetary Data System (PDS) Standards, Version 3.6.
