Description

This archive contains calibrated data from the ROMAP-MAG instrument onboard ROSETTA Lander, acquired during the AST1 (Steins fly-by) phase. It also contains documentation which describes the ROMAP experiment. The data archived in this data set conform to the Planetary Data System (PDS) Standards, Version 3.6.
