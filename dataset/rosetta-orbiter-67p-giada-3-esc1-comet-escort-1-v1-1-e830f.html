Description

The current data set (version V1.1) is superseding the previous released version of Comet Escort 1 data set (RO-C-GIA-3-ESC1-COMET-ESCORT-1-V1.0): an issue occurred in some tables was fixed; addressed all scientific RIDS. Comet Escort 1 Phase covers the period of time from the 21 November 2014 until the 10 March 2015. It started after Rosetta successfully completed the Prelanding Phase. The present DataSet collects the GIADA data of ESC1 phase. The GIADA Scientific phase started on 7 May 2014 and was devoted to the characterization of the 67P environment.
