Description

This dataset contains RAW DATA from the RPCICA instrument onmission ROSETTA during Comet escort 1.Data contains measurements of solar wind interactionwith the atmosphere of target comet 67P.Data set version 3 replaces a previously delivered data set.Important changes are the the expansion of data to a uniform resolution,Inclusion of the mode variable and new quality flags in the data andmoving information about software version, BAD_HV_MASK and SHADOW_MASKto the label.
