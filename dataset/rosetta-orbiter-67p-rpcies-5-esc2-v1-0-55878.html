Description

This dataset contains DERIVED DATA of the Rosetta RPCIES instrument taken during the comet escort 2 phase (ESC2). The target of this phase was comet 67P/CHURYUMOV-GERASIMENKO 1 (1969 R1). Included are the data taken between 11 Mar 2015 and 30 Jun 2015.
