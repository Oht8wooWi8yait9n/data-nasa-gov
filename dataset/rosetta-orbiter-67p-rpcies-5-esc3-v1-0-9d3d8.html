Description

This dataset contains DERIVED DATA of the Rosetta RPCIES instrument taken during the comet escort 3 phase (ESC3). The target of this phase was comet 67P/CHURYUMOV-GERASIMENKO 1 (1969 R1). Included are the data taken between 01 Jul 2015 and 21 Oct 2015.
