Description

This archive contains data from the RPC-MIP instrument onboard ROSETTA Orbiter, acquired in the vicinity of 67P/CG during the prelanding part 3 mission phase. It also contains documentation which describes the MIP experiment. The data archived in this data set conform to the Planetary Data System Standards, Version 3.6.
