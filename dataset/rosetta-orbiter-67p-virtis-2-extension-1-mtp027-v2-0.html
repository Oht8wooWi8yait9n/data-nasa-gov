Description

This release contains the digital numbers (DN) contained in the telemetry (TM) packages of the VIRTIS instrument on board of the spacecraft Rosetta. This volume contains data at the vicinity of comet 67P, from the EXTENSION 1 MTP027 phase, which occurred from 2016-03-09 to 2016-04-06. This version of the dataset (2.0) is produced by a fixed EGSE software. The old version of the software produced incomplete products, reduced by one line
