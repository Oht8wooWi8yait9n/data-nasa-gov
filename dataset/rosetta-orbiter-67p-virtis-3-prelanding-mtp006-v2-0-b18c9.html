Description

This release contains the calibrated data of the VIRTIS instrument on board of the spacecraft Rosetta. This volume contains data from the PRELANDING MTP006 phase, which occurred from 2014-08-01 to 2014-09-02 when approaching comet 67P. This data set V2.0 supersedes V1.0. It includes major updates on the data and documentation.
