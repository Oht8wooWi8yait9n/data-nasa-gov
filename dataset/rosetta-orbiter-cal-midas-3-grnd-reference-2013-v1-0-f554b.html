Description

The Micro-Imaging Dust Analysis System (MIDAS) is an instrument on theROSETTA Orbiter that will provide 3D images and statistical parametersof pristine cometary particles, collected in the vicinity of comet67P/Churyumov-Gerasimenko. This data set includes referencemeasurementdata acquired with the flight spare unit (FS) on ground, which wasusedfor improving the accuracy of the images gathered by the actual flightunit and to develop adequate measuement procedures for flight. Thetestdata was collected during several years and spawns several data sets,in order to keep the individual data set size on a reasonable level.The current dataset contains data from 2013.
