Description

The Micro-Imaging Dust Analysis System (MIDAS) is an instrument on the ROSETTA Orbiter that will provide 3D images and statistical parameters of pristine cometary particles, collected in the vicinity of comet 67P/Churyumov-Gerasimenko. This data set includes reference measurement data acquired with the flight spare unit (FS) on ground, which was used for improving the accuracy of the images gathered by the actual flight unit and to develop adequate measuement procedures for flight. The test data was collected during several years and spawns several data sets, in order to keep the individual data set size on a reasonable level. The current dataset contains data from 2014.
