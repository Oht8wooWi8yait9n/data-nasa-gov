Earth ScienceDNG Legacy DataAccess: public
View Official Record on data.nasa.gov

Description

This data set contains Spectroscopic and Continuum data, in the form of table files, taken during the Commissioning phase of the Rosetta mission by the MIRO instrument. These data have been calibrated to antenna temperatures.
