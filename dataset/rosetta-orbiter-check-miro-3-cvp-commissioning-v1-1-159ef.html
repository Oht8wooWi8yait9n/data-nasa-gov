Description

This data set contains Spectroscopic and Continuum data, in the form of table files, taken during the Commissioning phase of the Rosetta mission by the MIRO instrument. These data have been calibrated to antenna temperatures. Version 1.1 added UTC to the data files, added a GEOMETRY directory and incorporated a number of minor documentation additions and corrections.
