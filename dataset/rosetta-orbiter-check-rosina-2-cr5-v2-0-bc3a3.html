Earth ScienceDNG Legacy DataAccess: public

Description

This data set present engineering data of the COPS, DFMS and RTOF ROSINA sensors during the active checkout 12, the Lander panel test and Lutetia rehearsal test - Cruise 5 phase. Version 2.0 contains significant corrections to the V1.0 data set.
