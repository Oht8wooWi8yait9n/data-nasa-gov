Description

This dataset contains RAW DATA from the RPCICA instrument on mission ROSETTA during the commissioning phase. Data of the solar wind was obtained, as well as some data with very high background levels. Data set version 2 replaces a previously delivered data set. Important changes are the ordering of the energy levels which now go from low to high and that the quality flag in the labels is updated.
