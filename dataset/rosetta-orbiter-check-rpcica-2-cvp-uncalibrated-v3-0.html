Description

This dataset contains RAW DATA from the RPCICA instrument onmission ROSETTA during the commissioning phase. Data of the solarwind was obtained, as well as some data with very high backgroundlevels. Data set version 3 replaces a previously delivered data set.Important changes are the the expansion of data to a uniform resolution,Inclusion of the mode variable and new quality flags in the data andmoving information about software version, BAD_HV_MASK and SHADOW_MASKto the label.
