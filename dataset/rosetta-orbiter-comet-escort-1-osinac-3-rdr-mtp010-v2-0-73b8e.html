Description

This data set contains images acquired by the OSIRIS Narrow Angle Camera during the COMET ESCORT 1 phase of the Rosetta mission at the comet 67P, covering the period from 2014-11-21T23:25:00.000 to 2014-12-19T23:24:59.000. This version V2.0 supersedes previous deliveries of the same dataset.
