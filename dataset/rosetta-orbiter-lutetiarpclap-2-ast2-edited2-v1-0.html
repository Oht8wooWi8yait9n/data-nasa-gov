Description

This data set contains EDITED data from Rosetta RPC-LAP, acquired during the LUTETIA FLY-BY mission phase where the primary target was the asteroid 21 LUTETIA. It contains uncalibrated raw data, i.e. the digital output of the instrument. This version reorganizes the data into fewer files with longer time series and sorted by type of measurement. It also changes the previous value of VOLUME_ID=ROLAP_1008. The version number starts over from V1.0 due to a change in naming convention.
