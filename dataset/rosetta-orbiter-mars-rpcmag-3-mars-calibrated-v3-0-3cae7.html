Description

This dataset contains CALIBRATED DATA of the MARS Flyby (MSB). Included are the data of the very Flyby from February 23 until February 27,2007 and the data of the Passive Checkouts PC3 (August 29, 2006), PC4 (November 23 - December 21,2006) and PC5 (May 22, 2007)
