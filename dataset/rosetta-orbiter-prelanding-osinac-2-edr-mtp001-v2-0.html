Description

This data set contains images acquired by the OSIRIS Narrow Angle Camera during the PRELANDING phase of the Rosetta mission at the comet 67P, covering the period from 2014-01-20T10:00:00.000 to 2014-05-07T12:47:59.000. This version V2.0 supersedes previous deliveries of the same dataset.
