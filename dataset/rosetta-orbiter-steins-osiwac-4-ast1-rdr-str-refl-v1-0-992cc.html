Description

This CODMAC level 4 data set contains solar stray light corrected, radiometric calibrated and geometric distortion corrected (resampled) image data in in reflectance units (normalized and thus without unit), acquired by the OSIRIS Wide Angle Camera on the Rosetta spacecraft during the STEINS FLY-BY mission phase, covering the period from 2008-08-04T00:00:00.000 to 2008-10-05T23:59:59.000. The prime target is asteroid 2867 Steins. This version V1.0 is the first version of this dataset.
