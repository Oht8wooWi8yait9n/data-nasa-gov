Description

This data set contains derived electron and proton flux energies in MeV from the Standard Radiation Environment Monitor (SREM) instrument on the Rosetta spacecraft. These are CODMAC Level 5 derived data, and measure the radiation in the spacecraft environment during the AST1 (STEINS) mission phase.
