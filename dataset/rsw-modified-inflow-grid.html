RSW Modified Inflow Grid

DNG Legacy DataAccess: public
View Official Record on data.nasa.gov

Description

After discussions by the organizing committee, and some research using the RSW grids, a modification has been made on the RSW grids. The inflow boundary has now been moved so that it is located 1000" in front of the model to provide a more accurate simulation of the boundary layer along the wind tunnel wall.
