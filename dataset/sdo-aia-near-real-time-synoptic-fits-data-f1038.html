Description

Near-Real-Time (NRT) images are produced at a 3-minute cadence hierarchy with a 15 to 20 minute latency from T_OBS. Because of various latencies and parallelisms in the level 0 and level 1 NRT pipelines, data are occasionally produced out of time order. Gaps in NRT AIA synoptic data do not get filled. The most recent directory has the most recent NRT synoptic image for each wavelength. These images have fixed file names (no date-time in file name). The file named image times in the most recent directory has the time for the most recent file in that directory.
