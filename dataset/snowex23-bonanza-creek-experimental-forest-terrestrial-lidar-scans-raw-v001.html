Description

This data set contains unprocessed point cloud data created from terrestrial lidar scans (TLS) collected during the SnowEx 2023 campaign from the Bonanza Creek Experimental Forest near Fairbanks, Alaska. Data were collected in October 2022 (snow-off) and March 2023 (snow-on). Digital terrain models (DTMs) derived from the raw point cloud data are available as the <a href="https://doi.org/10.5067/R466GRXNA61S">SnowEx23 Bonanza Creek Experimental Forest Terrestrial Lidar Scans, Version 1 (SNEX23_BCEF_TLS) data set</a>
