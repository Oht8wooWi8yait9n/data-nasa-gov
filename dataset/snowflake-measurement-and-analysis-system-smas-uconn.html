Description

The Snowflake Measurement and Analysis System (SMAS) University of Connecticut (UCONN) dataset uses seven high-resolution cameras to reconstruct the three-dimensional structure of snowflakes based on photographs of the particles in freefall from multiple views. SMAS can measure and analyze multiple snowflakes at once. A CSV file is provided that includes additional details on each snowflake. The SMAS was deployed in 2023-2024. The dataset contains data from January 14, 2023 to March 21, 2024 as BMP images and a single CSV file.
