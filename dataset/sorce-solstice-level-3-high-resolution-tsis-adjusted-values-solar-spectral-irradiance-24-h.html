Description

Version 002 is the most recent version of this data product, and supersedes all previous versions. The SORCE SOLSTICE Level 3 High Resolution TSIS-Adjusted Values Solar Spectral Irradiance 24-Hour Means data product (SOR3SOLS_TAV_HIGH_NC) uses the temporal overlap of the Solar Radiation and Climate Experiment (SORCE) and the Total and Spectral Solar Irradiance Sensor (TSIS-1) Spectral Irradiance Monitor (SIM) instruments to create an alternate SORCE-SOLSTICE irradiance calibration, known as the TSIS-1 Adjusted Values (TAV). The SORCE-SOLSTICE Solar Spectral Irradiance (SSI) data products are provided from the SOLSTIVE MUV channel (200 - 310 nm) at an instrument spectral resolution of 0.1 nm, with the data interpolated to a 0.025 nm grid using a spline model. Irradiances are reported at a mean solar distance of 1 AU and zero relative line-of-sight velocity with respect to the Sun. All of the SOR3SOLS_TAV_HIGH_NC data are arranged in a single file netCDF file which can be easily read with any application that supports netCDF. There are netCDF variables which contain the date, Julian day, wavelength, irradiance value, irradiance uncertainty, irradiance repeatability, irradiance original uncorrected, and data quality.
