Description

Version 002 is the most recent version of this data product, and supersedes all previous versions. The SORCE SOLSTICE Level 3 TSIS-Adjusted Values Solar Spectral Irradiance 24-Hour Means data product (SOR3SOLS_TAV_TXT) uses the temporal overlap of the Solar Radiation and Climate Experiment (SORCE) and the Total and Spectral Solar Irradiance Sensor (TSIS-1) Spectral Irradiance Monitor (SIM) instruments to create an alternate SORCE-SOLSTICE irradiance calibration, known as the TSIS-1 Adjusted Values (TAV). The SORCE-SOLSTICE Solar Spectral Irradiance (SSI) data products are provided from the SOLSTICE MUV channel (200 - 310 nm) at an instrument spectral resolution of 0.1 nm. Irradiances are reported at a mean solar distance of 1 AU and zero relative line-of-sight velocity with respect to the Sun. All of the SOR3SIMD_TAV_TXT data are arranged in a single file in a tabular ASCII text file which can be easily read into a spreadsheet application. The columns contain the date, Julian day, minimum wavelength, maximum wavelength, instrument mode, data version number, irradiance value, irradiance uncertainty, and data quality. The rows are arranged with data at each wavelength over the full SOLSTICE MUV wavelength range, repeating for each day for the length of the measurement period.
