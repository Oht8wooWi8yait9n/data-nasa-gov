Description

These maps of small solar system bodies have been prepared by Philip Stooke of the University of Western Ontario. This data set includes 226 map sheets of five asteroids, five planetary satellites, and one comet, all prepared from spacecraft images. The data set was updated in 2012 with the addition of five new map sheets.
