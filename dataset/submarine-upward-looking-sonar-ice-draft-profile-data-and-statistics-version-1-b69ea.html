Description

This data set consists of upward looking sonar sea ice draft data collected by submarines in the Arctic Ocean. It includes data from both U.S. Navy and Royal Navy submarines. Data are provided as ice draft profiles and as statistics derived from the profile data. Statistics files include information concerning ice draft characteristics, keels, level ice, leads, un-deformed and deformed ice.
