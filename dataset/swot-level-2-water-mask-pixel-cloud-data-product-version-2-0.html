SWOT Level 2 Water Mask Pixel Cloud Data Product, Version 2.0

geospatialSWOTDNG Legacy DataAccess: public
View Official Record on data.nasa.gov

Description

Point cloud of water mask pixels (“pixel cloud”) with geolocated heights, backscatter, geophysical fields, and flags. Point cloud over tile (approx 64x64 km2); half swath (left or right side of full swath). Available in netCDF-4 file format.
