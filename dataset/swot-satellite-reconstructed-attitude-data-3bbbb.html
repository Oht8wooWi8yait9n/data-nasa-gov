SWOT Satellite Reconstructed Attitude Data

Earth ScienceScience Discovery EngineAccess: public
View Official Record on data.nasa.gov

Description

Satellite attitude reconstructed from combination of onboard gyro and star tracker data. Daily 26-hour files centered at 12:00:00 (TAI) provide quaternions to represent the rotation between the spacecraft body-fixed KaRIn Metering Structure Reference Frame and the inertial Geocentric Celestial Reference Frame. Available in netCDF-4 file format with latency of < 1.5 days.
