Description

The Tropospheric Emissions: Monitoring of Pollution (TEMPO) science data processing reference data is a collection of time-independent reference data that are used in the TEMPO Science Data Processing Center (SDPC) pipeline to create the TEMPO standard and near-real time data products. These reference data are provided to allow users to run the opensource code used in the TEMPO SDPC pipeline. The collection contains reference solar spectra, reference molecular absorption spectra, terrestrial surface reflectance tables, land cover data, digital elevation maps, and tables of hourly mean atmospheric structure and composition for each month of the year. The collection also includes TEMPO instrument calibration parameters. These data have a variety of temporal and spatial coverage, including many that are neither time nor spatially dependent, such as the reference data files that contain atomic data (e.g. molecular absorption spectra), which constitute physical properties of molecules. These files are provided in netCDF, HDF5, or ASCII formats. Most of the files have been compressed into zip files based on subdirectories used in the reference data directory tree of the SDPC pipeline software.
