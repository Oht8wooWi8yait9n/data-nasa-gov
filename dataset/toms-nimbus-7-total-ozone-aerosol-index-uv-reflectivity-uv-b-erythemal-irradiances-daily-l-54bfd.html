Description

The Nimbus-7 Total Ozone Mapping Spectrometer (TOMS) version 8 daily global gridded data product contains total column ozone, UV aerosol index, Lambertian effective surface reflectivity (Rayleigh corrected), and UV-B erythemal local noon irradiances. The data are mapped to a global grid of size 180 x 288 with a lat-long resolution of 1.00 x 1.25 degrees. These data are stored in the EOS Hierarchical Data Format (HDF-EOS). The TOMS data were produced by the Laboratory for Atmospheres at NASA Goddard Space Flight Center (Code 614).
