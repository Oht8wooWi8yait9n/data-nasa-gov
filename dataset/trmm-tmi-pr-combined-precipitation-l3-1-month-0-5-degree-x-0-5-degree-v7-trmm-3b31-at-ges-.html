Description

This is a combined rainfall product. 3B31 uses the high quality retrievals done for the narrow swath in 2B31 to calibrate the wide swath retrievals generated in 2A12. For each 0.5 degree box and each vertical layer, an adjustment ratio is calculated for the swath overlap region for one month. Only TMI pixels with 2A12 pixelStatus equal to zero are included in monthly averages, which effectively removes sea ice.
