Description

This data set from the Ulysses Gammay-Ray Bursts experiment contains 5-minute resolution filtered averages of cosmic gamma ray and solar X-Ray count rates. Count rate units are c/s. See Astron. Astrophys. Suppl. Ser., 92(2), 401-410, 1992 for more information.
