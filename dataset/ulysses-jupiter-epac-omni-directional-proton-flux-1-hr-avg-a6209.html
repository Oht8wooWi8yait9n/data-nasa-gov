Description

This data set contains Ulysses Energetic Particle Composition Experiment (EPAC) 1 hour averaged omni-directional proton flux data from the Ulysses Jupiter encounter 1992-Jan-25 to 1992-Feb-28. These data were recorded by Omni-directional Protons Spin Averages Telescopes (OPTL) 1-4.
