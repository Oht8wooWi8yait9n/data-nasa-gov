Description

The Pioneer Venus Radar Archive (PVRA) data set consists of the permanentarchive version of four data products from the Radar Mapper (ORAD) instrument on the Pioneer Venus Orbiter: the Pioneer Project's Radar Experiment Data Record (ORAD-EDR), Supplementary Experiment Data Record (SEDR), Radar Processing Archive (PVA), and Radar Composite Data Record (PVCD). The EDR's and SEDR's contain raw telemetry frames, uplink commands, and ancillary data necessary to reconstruct the spacecraft location and orientation. The PVA records were generated during subsequent processing at the Massachusetts Institute of Technology. The PVCD contains verified and edited radar observations. Each PVRA data directory contains data derived from a single orbit of the Pioneer Venus Orbiter
