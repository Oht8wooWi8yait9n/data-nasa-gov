Description

The VCO IR2 CDR data set contains products acquired by the IR2 instrument onboard the Venus Climate Orbiter (VCO, also known as PLANET-C and AKATSUKI) spacecraft. The data files are provided in FITS format with an HDU as IMAGE extension, and it also contains metadata to the header of the HDU.
