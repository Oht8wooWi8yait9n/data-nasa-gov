Description

The daily Intensive solution files in SINEX format are analysis products that are mainly designed for combination, for both within the IVS and with other space techniques, since they contain datum-free normal equations (decomposed normal equations). Secondly, they allow to estimate UT1 for each 1-hour Intensive session applying a selected datum. Thirdly, the files contain estimates for all parameters (site positions, polar motion, UT1-TAI, and LOD), but these parameters, except UT1-TAI, have been tightly constrained to a priori values. The files are in SINEX format providing also the covariance matrix of the estimates. The SINEX product files are available on the same frequency as the EOP-I products: 24 hours after each new session data base is available.
