Description

This data set (VG1-J-PRA-3-RDR-LOWBAND-6SEC-V1.0) contains data acquired by the Voyager-1 Planetary Radio Astronomy (PRA) instrument during the Jupiter encounter. The bounding time interval set for most Voyager 1 Jupiter PDS data sets is the Voyager project defined 'far encounter' mission phase boundary (1979-02-28 to 1979-03-22). Since, however, the PRA instrument is able to observe planetary phenomenon at much larger ranges than other fields and particles experiments, this boundary is artificial with respect to PRA.
