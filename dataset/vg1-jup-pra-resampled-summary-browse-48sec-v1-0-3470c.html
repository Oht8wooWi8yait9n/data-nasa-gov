Description

This data set consists of edited browse data derived from an original data set obtained from the Voyager 1 Planetary Radio Astronomy (PRA) instrument in the vicinity of Jupiter. Data are provided for 70 instrument channels covering the range from 1.2 kHz to 1326 kHz in uniform 19.2 kHz steps, each 1 kHz wide. Data are included for the period 1979-01-06 00:00:48 through 1979-04-13 23:58:24.
