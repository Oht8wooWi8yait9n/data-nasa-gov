Description

This data set (VG2-N-PRA-2-RDR-HIGHRATE-60MS-V1.0) contains dataacquired by the Voyager-2 Planetary Radio Astronomy (PRA) instrumentduring the Neptune encounter. Since the PRA instrument is able toobserve planetary phenomenon at much larger ranges than other fieldsand particles experiments, thus the PRA data cover a variable andlonger encounter period. PRA lowband data provided here cover theentire Neptune Encounter Phase (1989-05-25 to 1989-09-27).
