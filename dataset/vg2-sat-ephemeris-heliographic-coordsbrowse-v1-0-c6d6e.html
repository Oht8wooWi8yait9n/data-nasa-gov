Description

This data set consists of Voyager 2 Saturn encounter ephemeris data in Heliographic coordinates covering the period 1981-08-24 to 1981-09-02. Two versions, both covering the same time period, but containing slightly different data, are provided. One version was generated by the Voyager MAG team from Voyager 2 SEDR, the other by the PDS/PPI node using the VG2_SAT.TSP and PCK00006.TPC SPICE kernels.
