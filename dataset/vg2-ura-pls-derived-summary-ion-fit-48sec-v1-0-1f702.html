VG2 URA PLS DERIVED SUMMARY ION FIT 48SEC V1.0

Planetary ScienceScience Discovery EngineAccess: public
View Official Record on data.nasa.gov

Description

This data set contains the total ion density obtained from Voyager 2 PLS data (voltage range 10-5950 eV/Q) at Uranus by fitting the measured spectra with isotropic Maxwellian distributions.
