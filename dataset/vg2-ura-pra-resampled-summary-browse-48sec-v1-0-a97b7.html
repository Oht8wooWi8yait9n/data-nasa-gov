Description

This dataset consists of edited browse data derived from an original dataset obtained from the Voyager 2 Planetary Radio Astronomy (PRA) instrument in the vicinity of Uranus. Data are provided for 70 instrument channels covering the range from 1.2 kHz to 1326 kHz in uniform 19.2 kHz steps, each 1 kHz wide. Data are included for the period 1986:019:00:00 through 1986:031:23:59.
