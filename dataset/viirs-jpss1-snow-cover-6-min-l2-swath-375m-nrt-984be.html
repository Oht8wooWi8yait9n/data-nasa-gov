Description

The VJ110_NRT is Near Real Time (NRT) VIIRS/JPSS1 Snow Cover 6-Min L2 Swath 375m data set which reports the location of snow cover using radiance data acquired by the Visible Infrared Imager Radiometer Suite (VIIRS) on board the NOAA-20 - formerly the Joint Polar Satellite System-1 (JPSS-1) satellite. Snow cover is identified using the Normalized Difference Snow Index (NDSI) and a series of quality control screens. The VJ110_NRT product is provided in NETCDF format. More information can be found from NASA [Snow Cover Products](https://viirsland.gsfc.nasa.gov/Products/NASA/SnowESDR.html) at VIIRS Land website.
