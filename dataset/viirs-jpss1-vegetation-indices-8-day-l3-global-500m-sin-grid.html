Description

The NOAA-20 Visible Infrared Imaging Radiometer Suite (VIIRS) Near Real Time (NRT) Vegetation Indices 8-Day L3 Global 500m SIN Grid data, short-name VJ113A4N Version 2 (V2) data product provides vegetation indices every day by selecting the best available pixel over the period of previous eight days. The VJ113A4N includes three vegetation indices: The Normalized Difference Vegetation Index (NDVI), the Enhanced Vegetation Index (EVI), and the Enhanced Vegetation Index-2 (EVI2), layers for NIR reflectance; three shortwave infrared (SWIR) reflectance; red, blue, and green reflectance; pixel reliability; relative azimuth, view, and sun angles; and a quality layer all at 500-meter spatial resolution. More information about the product can be found in the [VIIRS Vegetation Indices User Guide]( https://landweb.modaps.eosdis.nasa.gov/data/userguide/VIIRS_VegIndices_UserGuide_C2.pdf) and details about V2 specific changes can be found in this [VIIRS Land V2 Changes document](https://landweb.modaps.eosdis.nasa.gov/data/userguide/VIIRS_Land_C2_Changes_09152022.pdf).
