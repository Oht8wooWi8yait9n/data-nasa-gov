Description

This data set reports the location of sea ice cover derived from radiance data acquired by the Visible Infrared Imager Radiometer Suite (VIIRS). Following the approach used by MODIS, the algorithm assumes that sea ice is snow covered and can be detected using the Normalized Difference Snow Index. The VIIRS instrument flies on board the Suomi National Polar-orbiting Partnership (NPP) satellite.
