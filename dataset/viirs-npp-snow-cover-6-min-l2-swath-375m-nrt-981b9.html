Description

The VNP10_NRT is Near Real Time (NRT) VIIRS/NPP Snow Cover 6-Min L2 Swath 375m data set which reports the location of snow cover using radiance data acquired by the Visible Infrared Imager Radiometer Suite (VIIRS) on board the Suomi National Polar-orbiting Partnership (SNPP) satellite. Snow cover is identified using the Normalized Difference Snow Index (NDSI) and a series of quality control screens. The VNP10_NRT product is provided in NetCDF format.
