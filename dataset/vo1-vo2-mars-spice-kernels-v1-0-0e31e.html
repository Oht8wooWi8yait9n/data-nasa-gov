Description

This data set includes a substantial collection of navigation and other ancillary data for the Viking Orbiter spacecraft (VO1 and VO2) in the form of SPICE kernels, which can be accessed using SPICE software. The SPICE data contains geometric and other ancillary information needed to recover the full value of science instrument data. In particular SPICE kernels provide spacecraft and planetary ephemerides, instrument mounting alignments, spacecraft orientation, spacecraft sequences of events, and data needed for relevant time conversions.
