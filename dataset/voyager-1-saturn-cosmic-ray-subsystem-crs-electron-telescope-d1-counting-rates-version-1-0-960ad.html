Description

* Data Set Overview * ================= This Data Set describes the Counting Rate Data from Detectors D1 and D2 in the Cosmic Ray Subsystem (CRS) Electron Telescope (TET) on Voyager 1 during the Saturn Encounter. The D1 Detector nominally responds to Electrons with Kinetic Energies above approximately 1 MeV, and the D2 Detector, above approximately 2.5 MeV (see Detector Description for Details). Note that the Instrument is saturated near the Maximum of Counting Rate of approximately 50,000 counts per second.
