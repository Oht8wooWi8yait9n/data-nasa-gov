Description

The Rossi X-ray Timing Explorer (RXTE) Index table was created for the purpose of providing a concise and easily accessible tracking of RXTE observations, both those already completed and those still scheduled to be done. Each entry in this table corresponds to a specific proposal/target combination or `complete observation&#39;, in contrast to the RXTE Master table in which each entry corresponds to a specific proposal/target/ObsID combination or `observing segment&#39;. A complete observation can consist of many (in some cases dozens) observing segments. This is a service provided by NASA HEASARC .
